# GMA Angus Ranch Website

A professional multi-page website for GMA Angus Ranch, a registered Black Angus seedstock operation in Merced, California.

## Inspiration
Designed in the spirit of Angus Media ranch websites, particularly littlegooseranch.com — clean, professional, focused on breeding philosophy, herd sires, and cattle for sale.

## Pages Included
- **index.html** — Homepage with hero, welcome, and feature cards
- **about.html** — Ranch history and philosophy
- **breeding.html** — Breeding program and key traits
- **herd-sires.html** — Featured sires (including Cardinal Warranty 901J)
- **for-sale.html** — Private treaty offering information
- **contact.html** — Contact details and social links

## How to Use
1. Open `index.html` in any web browser to preview the site.
2. All pages are linked together with a consistent navigation menu.
3. Images are stored in the `/images` folder.
4. To go live:
   - Upload the entire folder to any web host (Netlify, Vercel, traditional hosting, etc.).
   - Or simply open the files locally for review.
5. Customize content, add real cattle photos, update EPDs, and add a contact form if desired.
